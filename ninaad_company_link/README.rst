Company Link
============

Create a new Odoo company from an existing contact in one click.

Overview
--------

The **Company Link** module adds a **Create Company** action to Contacts. It
helps users create an Odoo company record from an existing contact without
having to create the company separately and link it manually.

Features
--------

* Create a company from an existing contact using a single action.
* Reduce repetitive manual data entry.
* Keep the workflow simple for organisations already recorded in Contacts.

How to Use
----------

#. Install the **Company Link** module.
#. Open the **Contacts** app.
#. Open the contact you want to use to create a company.
#. Run the **Create Company** action.
#. Review the newly created company record.

Configuration
-------------

No additional configuration is described as required by this module.
